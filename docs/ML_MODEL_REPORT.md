## 1. Overview

NetShield uses a dual-model ensemble for network intrusion detection:

1. **Isolation Forest** — Unsupervised anomaly detection (identifies unusual traffic patterns)
2. **XGBoost Classifier** — Multi-class supervised classification (identifies specific attack types)

Both models are trained independently on two benchmark cybersecurity datasets:
- **CIC-IDS-2017** (Canadian Institute for Cybersecurity)
- **UNSW-NB15** (University of New South Wales)

## 3. Feature Engineering & Preprocessing

### 3.1 Feature Selection
Raw CSV columns include network flow statistics automatically generated by CICFlowMeter:

- **Flow Duration**: Total time of the network flow
- **Packet Counts**: Forward and backward packet counts
- **Byte Statistics**: Total bytes, mean packet length, variance
- **Inter-Arrival Times (IAT)**: Mean, std, min, max for forward and backward
- **Flag Counts**: SYN, ACK, FIN, RST, PSH, URG
- **Window Sizes**: Initial TCP window bytes
- **Flow Rates**: Bytes/s, Packets/s

**Total features (CICIDS):** 78 numerical features  
**Total features (UNSW-NB15):** 49 features (3 categorical + 46 numerical)

### 3.2 Data Cleaning
```python
1. Strip whitespace from column names
2. Replace Inf/-Inf values with NaN
3. Drop rows with NaN values
4. Filter out classes with fewer than 10 samples (rare attacks)
```

### 3.3 Sampling Strategy
Due to the large dataset size (~2.8M rows), stratified sampling is applied:
- **15,000 samples per file** (8 files = up to 120,000 rows)
- Preserves class distribution through stratification

### 3.4 Label Encoding
```python
LabelEncoder().fit_transform(y)
# e.g., BENIGN → 0, DoS Hulk → 3, DDoS → 2, PortScan → 9
```

### 3.5 Feature Scaling
```python
MinMaxScaler().fit_transform(X)
# Scales all features to [0, 1] range
```

## 4. Model Training

### 4.1 Isolation Forest (Anomaly Detection)

| Parameter | Value |
|---|---|
| `n_estimators` | 100 |
| `contamination` | 0.1 (10% expected anomaly rate) |
| `random_state` | 42 |
| `n_jobs` | -1 (all CPU cores) |

**Output**: `-1` for anomaly (outlier), `1` for normal (inlier)

The Isolation Forest operates unsupervised — it learns what "normal" traffic looks like and flags statistically unusual flows without needing attack labels.

## 6. Risk Scoring Algorithm

Each network flow receives a **Risk Score (0–100)** computed as:

```python
def compute_risk_score(is_anomaly, threat_class, threat_prob):
    score = 0
    if is_anomaly:
        score += 40          # Anomaly detection contribution
    if threat_class != "BENIGN":
        score += (threat_prob * 60)   # Classification confidence contribution
    return min(max(int(score), 0), 100)
```

| Score Range | Risk Category | Interpretation |
|-------------|---------------|----------------|
| 0–19 | **Low** | Normal traffic |
| 20–49 | **Medium** | Suspicious activity |
| 50–79 | **High** | Likely attack |
| 80–100 | **Critical** | Confirmed high-confidence attack |
