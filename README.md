# NetShield AI: Network Anomaly Detection & Threat Monitoring System



NetShield AI is an AI-powered network security platform designed to monitor network traffic, detect suspicious activity, classify potential threats, generate security alerts, and provide centralized security analytics.



## Key Features



- User authentication and role-based access control

- Administrator and Security Analyst roles

- Network traffic monitoring

- Live Wi-Fi traffic capture using TShark

- Offline PCAP/PCAPNG analysis

- AI-based network traffic classification

- CICIDS2017 and UNSW-NB15 datasets

- Threat detection and severity assessment

- Security alerts and notifications

- Incident investigation and status management

- Security analytics dashboard

- Threat intelligence reporting

- PDF threat intelligence reports

- Audit logging

- Prediction history and monitoring workflows
